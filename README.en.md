# HALVETH Realms · Scarlet Garden

**Concise project guide · EN / RU**

An original procedural fantasy sandbox with an observatory, luminous groves, settlements and ruins. The documented desktop edition packages a JavaScript/WebGL game and local simulation server in an Electron application; installation, saves and controls are explained in the original README.

This is an independent game prototype with its own world. It does not replace or rebuild a Morrowind installation. Its own code uses MIT terms; Three.js and other dependencies retain their respective notices.

This manually edited guide summarizes the audited source. The original technical documentation remains the reference for commands, build requirements, exact versions and detailed evidence.
