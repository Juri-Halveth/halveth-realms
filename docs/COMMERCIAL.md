# Open source and a commercial game

The original code is released under standard MIT. Users may use, modify and sell copies while retaining the required copyright and license notices. Primary source: [OSI MIT license](https://opensource.org/license/mit). The code has no mandatory donation gate. Optional donations or sales are separate from the license grant.

## Concrete product direction

| Layer | Present edition | Commercial extension |
| --- | --- | --- |
| Open engine/game foundation | Local procedural browser world, ten guest sessions, original content | Public development and community-created regions |
| Hosted worlds | Local prototype server | Operated instances, backups, moderation, uptime and support |
| Finished editions | Playable technical foundation | Curated story campaigns, polished art, animation, sound and performance work |
| Creator work | Source cards and draft generator | Commissioned original regions, writing and character packs with explicit licenses |

There are no invented prices, promised returns, transferable game currencies or automatic charges in this build. Revenue depends on an actual product and willing customers. The value to sell is curation, service, original content and support.

## Roadmap before a paid public launch

1. Playtest exploration, camera, dialogue and a complete short story with several people.
2. Establish original visual identity, character animation, sound and accessibility targets.
3. Implement the chosen hosting model with authentication appropriate to public operation, moderation, backups, deployment and load testing.
4. Define actual paid deliverables, prices, support and the applicable checkout and privacy terms.
5. Keep a freely usable source release and a clear inventory of licenses for every shipped dependency and asset.

The earlier Morrowind mod remains separate. Bethesda/Rockstar/Marvel names and assets are not the commercial identity or content library of HALVETH Realms. The selected public HALVETH project sources are referenced as ideas; their licenses are not replaced by this project's MIT license.
