# Build with us

HALVETH Realms welcomes original code, game writing, accessible controls, procedural art and reproducible bug reports. Use `codex/` or another clearly named feature branch; keep changes small enough to play and review.

1. Run `npm test` and start `node server.mjs`.
2. Check the changed feature in the browser, including an appropriate narrow viewport.
3. Record what changed, why, the tested scope and remaining limitations.
4. Include licenses and authorship for any new third-party material. Referencing a source or franchise does not grant permission to bundle its assets.
5. Keep world histories, conversations, credentials, keys and `.local/` out of commits and releases.

Contributions to the original project code are offered under the MIT license. Existing dependency notices remain intact. Proposals from `npm run evolve` are drafts; review their story and gameplay consequences before incorporating them.

Public-server operation, a paid product launch, contract deployment and payment integration each require their own concrete configuration and validation. A passing test suite does not assert production readiness.
