# HALVETH Realms · Scarlet Garden

**Краткий путеводитель по проекту · EN / RU**

Самостоятельная процедурная фэнтезийная песочница с обсерваторией, светящимися рощами, поселениями и руинами. Описанная настольная версия объединяет игру JavaScript/WebGL и локальный сервер симуляции в приложении Electron; установка, сохранения и управление объяснены в исходной README.

Это независимый игровой прототип со своим миром. Он не заменяет и не перестраивает установленный Morrowind. Собственный код распространяется на условиях MIT; Three.js и другие зависимости сохраняют свои уведомления.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
